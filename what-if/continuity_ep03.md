# Серия 3 · библия непрерывности

Каждый план перед запуском сверяется с этим файлом. Если план что-то меняет (сдвигает предмет, меняет одежду, переносит действие), это сначала записывается сюда.

## 1. Правила генерации

1. **Один план = один клип Wan 3.0**, 480p, длина по действию: 2–5 секунд. Внутри клипа склеек нет.
2. **Сцепка кадров.** План в той же комнате, что и предыдущий, на той же камере или похожей, начинается с последнего кадра предыдущего плана (`start_image`). Wan не принимает одновременно `start_image` и референсы, поэтому в таких планах одежда и лица описываются словами полностью, по таблицам ниже.
3. **Вход в уже показанную комнату:** начальный кадр — та же комната без героя (вырезан из готового плана), конечный — первый кадр следующего плана. Так не меняются ни мебель, ни герой.
4. **Новый ракурс или новое место** (крупный план, другая комната) идёт с референсами: план локации + лист персонажа + при необходимости вырезка одежды из уже готового кадра.
4. **Листы с толпой не используем.** Каждый второстепенный персонаж даётся отдельной вырезанной картинкой (`assets/ep03/refs/`).
5. **Перед запуском проверяю:** одежду, предметы в кадре и их место, время суток, сторону кадра, кто где сидит, что в руках.
6. **После генерации проверяю раскадровку** по тем же пунктам. Брак переделываю только этим планом, с первым кадром из соседнего.

## 1a. Ритм

После каждого проявления скорости даём герою 2–4 секунды реакции: он замечает, удивляется, проверяет себя. Гэг без паузы не читается.

## 4. Застывший мир

- Wan не держит «застывший мир» по словам. Рабочий приём: одинаковый начальный и конечный кадр; двигается только герой, остальные стоят.
- Общий план застывшей кофейни — стоп-кадр с наездом камеры (бесплатно).

- Двигается только герой. Всё остальное неподвижно, включая пар, воду, птиц и пыль.
- Всё, что герой переставил, остаётся на новом месте во всех следующих планах. Это вносится в список ниже.

## 4a. Урок

Wan всё равно шевелит «застывших» людей в планах с действием героя. Проверять каждого второстепенного по кадрам; лишнее движение — резать или замораживать кодом (`tools/freeze.py`).


`freeze.py --world` путает героя с кирпичом и тёплыми лампами (тот же оттенок, что у худи), и птицы рядом с такими местами «оживают». Птиц и фон, куда герой не заходит, замораживаем `tools/hold_band.py` по полосе кадра. Если голова героя заходит в полосу, нужен `--hero-col --hero-shape`. Птицу, сквозь которую проходит герой, убираем из опорного кадра через `--patch`. Готовую серию правим `tools/patch_cut.py`, без пересборки.

Со `start_image` без референсов Wan теряет героя (джинсы вместо шорт, нет пучка). Для планов, где герой крупный или важен, — референсы листа; сцепку по кадру — только когда герой уже точно в кадре по образу.
