# Вставки серии 1 по блокам

Каждый `fxNN.json` накладывается на готовый блок 1080p командой
`python3 tools/fx_overlay.py IN.mp4 OUT.mp4 ep01_fx/fxNN.json`.
Кадры считаются по 24 к/с от начала блока (после вырезок в 07, 09, 13).

Принятые генерации: 01 `325ac9b5`, 02 `9b317ab0`, 03 `7d3a62d0`, 04 `c395eda5`, 05 `c22fbb4c`,
06 `6ede4fd5`, 07 `666e98ea`, 08 `4fd140a4`, 09 `2a379201` (без плана с часами), 10 `cacaa48c`,
11 `a42268b1`, 12 `78a4f063`, 13 `f3bde785` (без последнего плана). Блоки 06 - 13 в 480p, через Topaz 1080p.
