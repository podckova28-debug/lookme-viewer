# Канал: ребрендинг @htgcstories под «What If You Woke Up As…»

Объяснения по-русски, текст для вставки в YouTube по-английски (в блоках кода, копировать целиком).

Исходные данные: канал «How They Got Caught», @htgcstories, 666 подписчиков, 36 роликов (анимированные мини-доки про финансовые аферы). Самый сильный ролик про Theranos, около 5 тыс. просмотров. Новая серия: рисованная 2D-комедия в стиле мультфильмов 90-х, рассказчик говорит со зрителем на «you», персонажи молчат, сквозной персонаж Дэйв.

---

## 1. Название канала

| # | Название | Плюсы | Минусы |
|---|---|---|---|
| **1 (рекомендую)** | **What If You Woke Up As** | Совпадает с форматом названий серий, поэтому каждый ролик в поиске «what if you woke up as spider-man» продвигает и канал. Сразу понятно, о чём канал. | Длинное, на аватарке не читается (аватарке это и не нужно). Слово «woke» иногда считывают как политическое, но в этой фразе оно однозначно бытовое. |
| 2 | Dave Is Not Surprised | Строит бренд вокруг Дэйва, который есть в каждой серии. Запоминается, смешно само по себе. | Новый зритель не поймёт формат по названию; не ловит поисковые запросы. |
| 3 | Day One Powers | Коротко, легко как хэндл, оставляет место для серий не только про супергероев. | Безликое, похоже на десятки других каналов. |

**Рекомендация: «What If You Woke Up As»** (в шапке и описании можно писать с многоточием: «What If You Woke Up As…»). Название канала и название серий работают на один поисковый запрос, а Дэйв становится лицом канала через аватарку.

## 2. Хэндл (@)

Проверить доступность в YouTube Studio → Настройка канала → Основные сведения → Псевдоним. Варианты по убыванию:

```
@WhatIfYouWokeUpAs
@WhatIfYouWokeUp
@WokeUpAsToons
@DaveIsNotSurprised
```

Важно: старый хэндл @htgcstories после смены освобождается и примерно 14 дней закреплён за вами, потом его может занять кто угодно. Старые ссылки youtube.com/@htgcstories перестанут вести на канал, ссылки на конкретные видео продолжат работать.

## 5. Баннер (шапка)

Размер файла 2560×1440, всё важное в центральной безопасной зоне 1546×423 (на телефоне видна только она).

- Фон: тёплая утренняя городская улица в стиле серии (кирпичные дома, жёлтый школьный автобус вдали), слегка размытая.
- Слева в безопасной зоне: Дэйв по пояс, в синем халате, с белой кружкой, смотрит в камеру без эмоций.
- Справа: силуэты «героев дня» без логотипов и фирменных эмблем: парень в красном худи и плавательных очках вверх ногами, огромная зелёная рука с чемоданом, размытый жёлтый след скорости. Узнаваемо, но ни одного товарного знака.
- Текст (шрифт Bangers из `assets/fonts`, жёлтый #FFE100 с толстой чёрной обводкой):

```
WHAT IF YOU WOKE UP AS...
New superpower every week. Same roommate.
```

Короткий вариант слогана для мест, где мало места: `New powers. Same Dave.`

## 6. Аватарка

Дэйв крупным планом: лысая голова, большая тёмная борода, круглые очки, кружка у губ закрывает рот, взгляд прямо в зрителя, полное спокойствие. Плоский жёлтый фон (#FFE100), толстые чёрные контуры, без текста. Лицо занимает центральные 70 %, чтобы круглая обрезка ничего не съела. Читается даже в 48 px в комментариях. Дэйв есть во всех сериях и не принадлежит ни одной студии, поэтому это безопасное и узнаваемое лицо канала.

## 9. График выхода

- **1 полная серия в неделю**, в один и тот же день (например, пятница). Серия 1 уже обещает в финале «Next week, Dave gets a new roommate» с зелёной рукой, поэтому через неделю обязательно выходит Hulk (ep2), затем Flash (ep3), затем Superman (ep4).
- **3-4 Shorts на серию**, по одному через день между выходами: первый Short за 1-2 дня до серии как тизер, остальные после, с привязкой «Related video» на полную серию.
- **1 пост в сообществе** в день выхода: кадр с Дэйвом и вопрос «Who should you wake up as next?». Ответы становятся темами серий.
- Первые 4 недели не менять день и время: так алгоритм и зрители быстрее привыкают.

## 10. Пошаговый ребрендинг в YouTube Studio

Делать в один вечер, за 1-2 дня до выхода первой серии.

1. **Сохранить старое.** Скачать резервные копии обложек и описаний старых роликов (Studio → Контент). Создать плейлист `Archive: How They Got Caught` и добавить туда все 36 роликов.
2. **Название.** Studio → Настройка канала → Основные сведения → Название → `What If You Woke Up As`. Название можно менять 2 раза за 14 дней. Если канал подтверждён (галочка), смена названия её снимает; здесь её нет, терять нечего.
3. **Псевдоним.** Там же → Псевдоним → `@WhatIfYouWokeUpAs` (или следующий свободный из раздела 2).
4. **Описание.** Там же → Описание → вставить текст из раздела 3. Добавить ссылку на будущий плейлист эпизодов.
5. **Аватарка и баннер.** Настройка канала → Брендинг: загрузить аватар (минимум 98×98, лучше 800×800 PNG) и баннер 2560×1440. Водяной знак (кнопка «Подписаться» на видео): маленькая версия аватарки Дэйва, показывать «в конце видео».
6. **Ключевые слова и страна.** Studio → Настройки → Канал → ключевые слова из раздела 4, страна проживания.
7. **Настройки загрузки по умолчанию.** Studio → Настройки → Загрузка видео: категория `Comedy` (сейчас, вероятно, стоит Education или News), язык English, «Не для детей» по умолчанию, теги по умолчанию: `what if you woke up as, superhero parody, animated comedy`.
8. **Главная страница.** Настройка канала → Макет: трейлер для неподписанных (раздел 7), разделы «All Episodes» и «Day One Shorts». Раздел со старыми роликами убрать с главной.
9. **Публикация серии 1.** Загрузить по `channel/ep01_spiderman_upload.md`, добавить в «All Episodes», выставить конечную заставку. Shorts по `channel/ep01_shorts.md`.
10. **Старые ролики: скрывать постепенно, Theranos оставить открытым.** Для партнёрской программы засчитываются только часы просмотра **публичных** роликов за последние 12 месяцев. Как только ролик скрыт по ссылке или удалён, его часы перестают считаться. Поэтому:
    - ролик про Theranos (около 5 тыс. просмотров, основная часть часов просмотра) остаётся **публичным**, пока канал не примут в YouTube Partner Program (1000 подписчиков и 4000 публичных часов за 12 месяцев либо 10 млн просмотров Shorts за 90 дней);
    - перед скрытием открыть Studio → Аналитика → Контент → «Время просмотра (часы)» за 365 дней и оставить публичными все старые ролики, у которых заметное время просмотра; скрывать только ролики с почти нулевыми часами;
    - скрывать по ссылке (Unlisted), не удалять: ссылки и комментарии сохраняются, ролик можно вернуть;
    - после приёма в YPP можно скрыть и Theranos.
11. **Не пугать алгоритм.** Не скрывать все 36 роликов за один день. Пока серия набирает свою аудиторию, старые ролики в плейлисте Archive никому не мешают.
12. **Синтетический контент.** Чекбокс «Изменённый или синтетический контент» нужен для реалистичного видео; для явно мультяшной анимации он не требуется. Если сомневаетесь, отметить его: на показы это не влияет.
13. **Через неделю проверить** в Аналитике → Аудитория, что новые зрители приходят на серию, а не на старые ролики, и что CTR обложки серии 1 не ниже 4-5 %. Если ниже, заменить обложку на вариант B из `ep01_spiderman_upload.md` (функция Test & Compare в Studio позволяет сравнить до трёх обложек).
