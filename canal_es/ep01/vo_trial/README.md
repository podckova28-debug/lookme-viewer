# Проба голоса рассказчика (narrador)

OmniVoice на CPU, голос по описанию «male, middle-aged, low pitch», без клона
реального человека. Якорная фраза `_anchor_narrador.wav` сгенерирована по
описанию, остальные реплики клонированы с неё, чтобы весь ролик звучал одним
голосом. WAV 24 кГц моно, тишина по краям обрезана. Темп 1.0.

| id | длина | Whisper (es) |
|---|---|---|
| s01_01 | 2,0 с | Imagina que puedes detener el tiempo. |
| s01_02 | 5,3 с | Todo el mundo se queda congelado, tus compañeros, el balón, y Nacho a mitad de un estornudo. |
| s01_03 | 0,8 с | Suena increíble. |
| s01_04 | 1,0 с | Y lo es. |
