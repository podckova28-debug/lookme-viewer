# Стилизованные 3D-кадры

3D-сцена на Three.js 0.170 (MIT), но в стиле канала, а не «голые» фигуры:

- **Фасады, тротуар и небо** вырезаны из нашего AI-фона (`../anim/cut/bg/*.jpg`) и натянуты на 3D-дома как текстуры.
  Освещение мультяшное (toon, 3 ступени), рёбра обведены тонкой сливовой линией, как в 2D.
- **Люди** — наши персонажи-нарезки (`drawChar` из `../anim/lib.js` + `cutout.js`) на плоских карточках,
  которые всегда смотрят в камеру: те же лица, мимика, походка, руки на пружинах.
- **Капли** — наша 2D-капля (овал с обводкой и бликом) спрайтами: до хлопка струи, после хлопка висящие бусины.
- **Эффект остановки времени** — наш `compose2`: мир серый, герой цветной, круговая волна от хлопка и «¡CLAP!».

## Запуск
```bash
npm install
python build_audio.py ../ep01/vo audio.wav          # печатает метки {"clap","walk","end"}
node still3d.js rain.html out/f '<метки>' 2 5 9      # стоп-кадры для проверки
node render3d.js rain.html out.mp4 <end> '<метки>' audio.wav
```
Рендер: Chromium без видеокарты (SwiftShader), 24 к/с. 12 секунд 1080p рендерятся примерно за 2 минуты.

## Что ещё можно
- вертикальная версия для шортсов (поменять размер кадра и угол камеры);
- такие же кадры для других мест: застывшая вечеринка, пролёт над городом, научные вставки.
