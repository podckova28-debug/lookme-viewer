## Проверка whisper (`qa_whisper.tsv`)

faster-whisper small, язык es, 16 кГц; совпадение = доля совпавших слов без ударений и пунктуации.

Первый прогон нашёл 9 настоящих ошибок: s06_05 («Se quedes tú»), s07_03, s09_01 («Rolema»), s11_01 («varo»), s12_05 («Bijo Cala»),
s13_02, s14_01, s14_08 («Dregla»), s15_06 («abrí»). Для каждой сделано 3 новых дубля, оставлен лучший по whisper; 8 из 9 теперь верны.
s14_01 «¿…Rizos?» (неуверенный шёпот одним словом) whisper во всех дублях слышит «Resos» — оставлен оригинал, проверить на слух.
