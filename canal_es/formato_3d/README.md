(youtu.be/3tpaWHaiLQ8, 4 ноября 2026). В ролике: сценарий через ИИ, озвучка ElevenLabs,
3D-сцены на Three.js, сборка в Remotion, «бесплатный плагин» и «мастер-промпт» по ссылке

## Как устроено

1. **Сцена** `scene.html`: один файл, Three.js 0.170.0 (MIT) из `node_modules`.
   Всё, что видно в кадре, это функция времени: `window.renderAt(t)` рисует кадр
   в секунду `t`. Случайность с фиксированным зерном, поэтому каждый рендер одинаковый.
   Размер кадра и метки сюжета приходят в адресе: `?w=1080&h=1920&cues={...}`.
2. **Метки сюжета** считает `render.js` по длинам реплик: `freeze` (хлопок, мир
   сереет, капли становятся бусинами), `walk` (герой идёт), `arrive` (дошёл), `end`.
   Картинка всегда попадает в озвучку, даже если реплики перегенерировали.
3. **Озвучка**: реплики s08_01–s08_06 с паузами 0,6–1,0 с, склеены ffmpeg
   (`adelay` + `amix`), 48 кГц.
4. **Рендер**: headless Chromium (SwiftShader, без видеокарты) → кадр за кадром
   `canvas.toDataURL('image/jpeg', 0.92)` → ffmpeg `libx264 crf 18`, 30 к/с, AAC 192k.

## Запуск

```bash
npm install three@0.170.0
node preview.js            # 5 стоп-кадров в preview/ для проверки
node render.js 1080 1920 prueba_1080x1920.mp4
node render.js 1920 1080 prueba_1920x1080.mp4
```

Playwright берётся из системы (в облачной сессии он предустановлен).

## Сцена «мир застыл» (s08, дождь)

- до хлопка: цветная улица, дождь падает струями;
- хлопок: белая вспышка 0,2 с, мир за 0,6 с уходит в серый, капли зависают;
- камера медленно въезжает в застывшие капли;
- на «Caminas a casa esquivándolas»: оранжевый герой с синим рюкзаком идёт по
  середине улицы, капли рядом с ним раздвигаются;
- люди серые, застыли на полушаге, у половины зонты.

## Ограничения

- Стиль простой: фигурки из капсул, без лиц и мимики. Для объяснялок (наука,
  «что если») это нормально, для сюжетных сцен с эмоциями Renata и героя слабее,
  чем текущие персонажи-нарезки.
- Каждая новая сцена пишется кодом: это время Claude, не кредиты.
