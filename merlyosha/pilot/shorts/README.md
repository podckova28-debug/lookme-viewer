# Shorts №1 · «Две цифры на ценнике стиралки»

`render/shorts-01-9x16.mp4` — готовый вертикальный ролик 1080×1920, 37 секунд.

**Как собран:**
- `frames/` — пять вертикальных кадров, сгенерированных по эталонному листу персонажа (`../../model-sheet/turnaround.png`) и палитре.
- `clips/` — те же кадры, оживлённые через Kling 3.0 (по 5 секунд, без звука).
- `captions/shorts_words.json` — пословные таймкоды озвучки (faster-whisper, модель small, русский).
- `captions/shorts_captions.ass` — субтитры: фразы по 1–3 слова, Montserrat ExtraBold 92 px, белый с обводкой #202020, активное слово подсвечено мятным; позиция по центру, чуть ниже середины кадра, вне зоны интерфейса.
- `tools/make_captions.py` — собирает ASS из пословных таймкодов; разбивка на фразы задана вручную списком `sizes`.
- `tools/build_shorts.py` — раскладка сцен по таймлайну озвучки и сборка через ffmpeg.

**Что менять, если нужно:** разбивку фраз — в `sizes` внутри `make_captions.py`; цвет подсветки — константа `HL` (BGR); положение субтитров — `\pos(540,1180)`; раскладку сцен — список `plan` в `build_shorts.py`.

В ролике нет логотипов и упоминаний бренда.
