# Озвучка пилота №1

| Файл | Что это | Длительность |
|---|---|---|
| `pilot-01-voice.mp3` | Полный выпуск одним треком, голос Liam (ElevenLabs через vidIQ), русский | 3:37 |
| `shorts-01-voice.mp3` | Shorts-версия, тот же голос | 0:37 |
| `test-hook.mp3` | Тест хука голосом Alexey (Seed Audio, тон +3) для сравнения тембра | 0:14 |
| `pilot-01-voice-aligned.srt` | Субтитры выпуска, таймкоды пропорционально ужаты под реальную длину трека | до 3:37 |
| `shorts-01-voice-aligned.srt` | То же для Shorts | до 0:37 |

Голос читает быстрее, чем заложено в сценарии (3:37 вместо 4:25), поэтому на монтаже есть запас около 50 секунд на паузы, гэги и карточки. Выровненные SRT получены масштабированием, а не пословной синхронизацией: перед публикацией прогоните их через автосинхронизацию YouTube или подправьте вручную на границах блоков.

Если тембр Liam покажется слишком взрослым, варианты: детский или молодой голос в ElevenLabs, либо клонированный голос актёра. Текст в `pilot-01-script.md` менять не нужно, числа уже записаны словами.
