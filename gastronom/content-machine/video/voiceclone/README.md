# Бесплатный голос Михалыча — локальный клон Alexey (voiceclone/)

**Правило: платную озвучку не запускать.** Пользователь: «Мы договаривались что озвучка бесплатно». Озвучка Михалыча
делается этим клоном, кредиты на голос не тратятся. Пресет Alexey в Higgsfield (`7c2133e5…`) — только образец.

## Как устроено
- Модель — Chatterbox Multilingual (Resemble AI), лицензия MIT: коммерческое использование разрешено, канал монетизируется.
  Говорит по-русски, клонирует голос по одной реплике-образцу.
- Образец — `ref_alexey.wav`: одна чистая реплика Alexey на 10 с из ролика «На воде» (C4, уже оплаченная).
- Ударения ставит RUAccent: `stressed` из `qa_out/textgate.json`, «+» превращается в знак ударения U+0301, его модель
  понимает. В словах с одной гласной знак снимается: RUAccent ставит его на предлоги, и клон бьёт ударение в «на́».
- Скорость на CPU (4 ядра): реплика 10 с — около 45 с, ролик на 7 минут — около 35 минут. Если параллельно идёт
  проверка или рендер, в 3–5 раз медленнее.

## Установка (один раз, ~3 ГБ модели)
```bash
python3.11 -m venv cbx_env
cbx_env/bin/pip install --index-url https://download.pytorch.org/whl/cpu torch==2.6.0 torchaudio==2.6.0
cbx_env/bin/pip install chatterbox-tts==0.1.7
```
Torch ставить только с CPU-индекса: с PyPI приходит сборка с CUDA на несколько гигабайт.

## Озвучка ролика
```bash
python3.11 qa/textgate.py <проект>/script.py --json <проект>/qa_out/textgate.json        # ударения и блок «ё»
cbx_env/bin/python voiceclone/clone_tts.py --project <проект> --ref voiceclone/ref_alexey.wav --take c --seed 0
cbx_env/bin/python voiceclone/clone_tts.py --project <проект> --ref voiceclone/ref_alexey.wav --take d --seed 1 --ids <забракованные>
python3.13 qa/voiceqa.py --lines script.py --takes vo_takes --risk qa_out/textgate.json --out qa_out/voice.json   # из папки проекта
```
- Дубли пишутся в `<проект>/vo_takes/<id>_<take>.wav`, дальше как обычно: `voiceqa` выбирает лучший дубль, `vopost` ставит паузы.
- Проверка голоса — обычная (`--engine minimax`, по умолчанию): у клона детектор ударения работает как у Alexey.
- Клон иногда смазывает слово: «чуть ли» → «шуки», «выхлопной» → «быхлопной». Поэтому забракованные реплики переозвучиваются
  с другим `--seed`, это бесплатно.
- Иногда клон дописывает после фразы несколько секунд бормотания или дыхания (immortal D2: 12,5 с вместо 7,5).
  voiceqa ловит это проверкой `tail`; дубль можно обрезать по концу фразы (`ffmpeg -t`), если сама фраза чистая.
- Если ударение в омографе не выходит ни у Alexey, ни у клона («воды на километр»), фраза переписывается без омографа.
- Темп клона как у Alexey: в `cut.py` стоит `TEMPO = 1.0`.

## Насколько похоже — `similarity.py`
Косинус голосового отпечатка к среднему отпечатку 56 реплик Alexey:

| Что | Сходство |
|---|---|
| Alexey к самому себе (другие его реплики) | 0,97 (мин 0,92) |
| клон, 6 реплик | 0,94–0,96 (мин 0,91) |
| Silero eugene (прошлый бесплатный голос) | 0,72 |

Клон лежит в разбросе самого Alexey, Silero — заметно другой голос. Сравнение на слух: `compare/alexey_vs_klon.mp3`
(в каждой паре сначала Alexey, потом клон).

## Акцент и ударения: проверять сплошь, брать лучший из 5–7 дублей (12 нояб, «Механик 90-х»)
Пользователь: «Проверь весь ролик на акцент и ударения — очень много ошибок», хотя voiceqa прошёл чисто: она слушает
ударение только в словах из словаря риска. Сплошная проверка `qa/stress_audit.py` (каждое слово из 2+ слогов)
нашла 43 подозрения в 28 репликах из 59. Почти все — ударение уехало на первый слог («ма́шин», «по́чти», «ко́пейки»,
«клю́чей», «Тво́я», «мо́я»): это системный акцент клона, а не случайность одного дубля.
- Настройки (exaggeration, cfg, temperature) заметно не помогают: разброс между сидами больше, чем между настройками.
- Помогает выбор: `qa/pick_best_take.py` по оценкам stress_audit из 5–7 дублей — 43 → 10 подозрений.
- Порядок для следующих роликов: синтез 3 дублей на реплику сразу → `stress_audit.py --take <t>` по каждому →
  `pick_best_take.py` → дозапись 4 дублей для реплик с ударными ошибками → снова выбор → voiceqa → монтаж.
- Детектор шумный в коротких словах («это», «этот», «или»): их подозрения низкого приоритета.
- Если и после этого слышно много ошибок — честно сказать пользователю, что это предел бесплатного клона.
