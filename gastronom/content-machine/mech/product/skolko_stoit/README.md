# «Михалыч, сколько стоит?» — оценщик стоимости ремонта

Человек описывает симптом, машину, пробег и город. Михалыч называет вероятные причины, вилку цены (сам / сервис / дилер),
план от бесплатной проверки к ремонту, порог переплаты и фразы для мастера.

- `prompt.md` — правила оценщика (v2, после слепого теста). Страница подставляет их в запрос к модели целиком.
- `page_template.html` + `style_v3.css` → `build.py` → `mihalych_cost.html` (прототип, artifact с capability `sample`).
- `demo_answer.json` — пример ответа, который страница показывает до первого запроса.
- `blind_test/` — слепой тест на 30 реальных случаях с drom.ru: входные данные, правда, ответы, оценка (`score.py`).

## Слепой тест (ноябрь 2026, правила v1)

Оценщик видел только описание случая и правила, итог ремонта лежал в отдельном файле.

| Метрика | Результат | Порог |
|---|---|---|
| Первая причина верна | 16/30 = 53% | — |
| Настоящая причина в первых трёх | 23/30 = 77% (та же деталь — 19/30 = 63%) | ≥ 70% ✅ |
| Реальный счёт в вилке найденной причины | 11/26 = 42% | ≥ 60% ❌ |
| Счёт в вилке или промах не больше 20% за край | 18/26 = 69% | — |

Почему счёт выходил за вилку (8 случаев):
- в одном счёте несколько ремонтов: сцепление вместе с кулисой, колодки с дисками, ступица с ШРУСами (4 случая);
- владелец выбрал не тот вариант ремонта: новый вариатор вместо ремонта, ремкомплект суппорта вместо нового, ремонт платы вместо мехатроника (3);
- недооценена переборка механической коробки (1).

Причину не нашёл в 4 случаях: только лампа «проверьте двигатель» (2), обрыв ремня ГРМ при «заглох и не заводится», заклинивший термостат.

Что поменяли в v2 (правила 10–13): попутный ремонт в `extra` с ценой; вилка «ремкомплект/ремонт — новый узел» для дорогих узлов;
обязательный сценарий обрыва ГРМ; при одной лампе без кода — низкая уверенность и первым шагом считать код ошибки.
Влияние v2 ещё не измерено: нужен новый набор случаев, не этот.

Оговорки: все случаи с drom.ru, итоги у владельцев часто примерные, 9 случаев — ремонт своими руками
(сравнивали с вилкой запчастей), в первой трети оценщик пересчитывал суммы своим скриптом и брал свои дилерские ставки.
