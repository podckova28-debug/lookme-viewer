# Музыка канала «Болезни» (для всех серий)

Сгенерирована в vidIQ (generate_music, royalty-free, инструментал), по 25 кредитов vidIQ за трек.
- `main_theme.mp3` (2:48) — основная: пицциката, фагот, кларнет, глокеншпиль, лютня, ~110 BPM, игриво.
- `sneaky_theme.mp3` (1:27) — «злодей подкрадывается»: контрабас, бас-кларнет, клавесин, ~80 BPM, смешно-тревожно, не хоррор.
- `today_theme.mp3` (1:25) — «сегодня»: укулеле, гитара, хлопки, ~118 BPM, светло.
В монтаже треки зацикливаются с кроссфейдом 3 с и приглушаются под голос.
