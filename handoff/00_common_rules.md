# Общие правила для всех каналов (обязательны в каждом чате)

- Отвечать пользователю по-русски, коротко и по делу. Ничего не публиковать самим (YouTube/Instagram выкладывает пользователь);
  готовить пакеты: видео ≤ 100 МБ, обложка 1280×720, README с названием, описанием, таймкодами, тегами и настройками.
- Никакой накрутки, сервисов раскрутки, взаимных подписок. Не делать ИИ-«персон», которые выдают себя за реальных людей.
- Голос: только Chatterbox с синтетическими опорными голосами Kokoro (коммерческая лицензия). Не клонировать голоса реальных людей,
  не использовать OmniVoice. Кредиты Higgsfield на озвучку не тратить. В тексте для TTS не писать «often» (писать «offen»).
- Каждый кадр проверять: лишние руки/пальцы, анахронизмы, неверные надписи и иероглифы, подписи не закрывают лица.
- Надписи на экране: Bebas Neue, белые заглавные, красная неровная полоса снизу, без разделителей «·».
- На каждом ролике YouTube: раскрытие ИИ (Altered or synthetic content) = ДА.
- Алгоритм: новое видео тестируется на небольшой группе; решают CTR (норма 4–10 %) и удержание (≥ 40 % для 6–10 мин).
  Через 48 ч смотреть CTR, досмотр и график удержания; хук = сцена + парадокс + число + вопрос; каждая глава кончается крючком.
- Git: работать в своей ветке, коммиты с подписью
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` и `Claude-Session: <ссылка своей сессии>`; без force-push; PR не создавать без просьбы.
- Личные данные пользователя (почта и т. п.) никуда не передавать.
- Аватарки для всех каналов: `handoff/avatars/` (по 2 варианта, превью `preview_all.jpg`).
