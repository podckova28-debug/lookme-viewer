## 3. Решения по каналам

### ЯДРО №1: «Дело закрыто» (RU, long)

## 4. Система: как это работает каждую неделю

### Недельный ритм
| День | Что делаем |
|---|---|
| Понедельник | Ресёрч: отбор 7 дел RU + 4 дел EN на неделю по формуле заголовка. Сценарии на 3 дня вперёд. |
| Вторник–суббота | Производство по пайплайну. 1 RU long в день, EN long через день. 2 shorts из каждого long. |
| Ежедневно, 20 минут | Ответить на комментарии первых 2 часов (алгоритм), запостить shorts, пост в Telegram. |
| Пятница | Разбор метрик недели в трекере: CTR, средний % просмотра, просмотры за 48 ч. Решение: что повторять, что убрать. |
| Воскресенье | Выходной от производства. Только планирование. |

### Пайплайн одного видео (чеклист, не пропускать шаги)
1. Дело выбрано по формуле (годы / улика / обычные люди / приговор вступил в силу).
2. Источники сохранены (ссылки на приговор, новости). Для RU: sudact.ru, ГАС «Правосудие», региональные СМИ. Для EN: court records, local news, Murderpedia.
3. Сценарий: хук в первые 15 секунд (улика или поворот), структура «что случилось → как искали → что выдало → приговор».
4. Фактчек сценария по источникам (имена, даты, сроки).
5. Озвучка, монтаж, визуал (свои карты, схемы, таймлайны; не стоковые кадры на весь ролик).
6. Три заголовка, три обложки, выбрать тест.
7. Описание: источники, ссылка на Telegram, таймкоды.
8. Публикация по расписанию, закреплённый комментарий с вопросом к аудитории.
9. Нарезка 2 shorts, расписание на Shorts / TikTok / VK Клипы / Telegram.
10. Дубль long на Дзен и VK Видео.
11. Строка в трекере.

### Единый трекер
Шаблон в файле `tracker-template.csv` рядом с этим планом. Один файл (Google Sheets) с вкладками:
`Календарь`, `Видео-лог` (дата, канал, заголовок, CTR, средний % просмотра, просмотры 48 ч / 7 дн), `Доход`
(по источникам, по месяцам), `Эксперименты`, `Рекламодатели`.
Без этого файла ты не узнаешь, что работает, и через месяц снова откроешь новый канал.

### KPI, которые смотрим (и только они)
- CTR обложки: цель >5 %, <3 % означает менять обложку.
- Средний % просмотра: цель >40 % для 10-минутного видео.
- Просмотры за 48 ч: главный предиктор. Видео ниже медианы канала после 48 ч не спасаем, идём дальше.
- Подписчики в Telegram: рост в неделю.
- Доход по источникам: раз в неделю одной строкой.

## 6. Чего не хватает («приблуды»)

## 7. Риски и как их гасим

1. **Отказ YPP за «повторяющийся / массово производимый контент».** Главный риск для AI-озвученных каналов.
   Гасим: оригинальные сценарии, источники в описании, собственная графика (карты, таймлайны), единый голос-персонаж,
   ответы в комментариях. Не заливать по 3 видео в день.
2. **Авторские права на кадры и фото.** Использовать минимум чужого видео, свои схемы, фото в рамках цитирования,
   не брать телевизионные сюжеты целиком.
3. **Юридический риск в RU true crime.** Только дела с вступившим в силу приговором, формулировки «по данным суда»,
   источники в описании. Не трогать открытые дела и несовершеннолетних.
4. **Страна каналов.** Вьетнам у HTGC и Россия у «Дело закрыто» могут заблокировать выплаты. Проверить до подачи.
5. **Выгорание пайплайна.** 7 RU + 4–5 EN в неделю это потолок для одного человека даже с автоматизацией.
   Если проседает качество, сначала режем EN до 3, а не RU.
6. **Ставка на один формат.** Если YouTube ужесточит условия для faceless-каналов, Telegram и Дзен остаются.
